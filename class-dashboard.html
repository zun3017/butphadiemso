Cấu Hình Kết Nối Google Sheet Mới

Khi Thầy tạo Google Sheet mới và triển khai Apps Script mới, Thầy chỉ cần mở file `js/config.js` và thay đổi URL tại biến SCRIPT_URL.

  • File mã nguồn Google Apps Script mẫu nằm trong file `GoogleScript.gs` của thư mục dự án.
  • Folder Drive nộp bài được cấu hình tại HOMEWORK_DRIVE_FOLDER.
  • Folder Drive giao bài được cấu hình tại ASSIGNMENT_DRIVE_FOLDER.
